## Recomendação — qual taxonomia usa cada armadura

> **Incorporado ao `taxonomias.md`:** cada bloco tem a linha **Armadura** com a
> versão "tanque" (arquétipos defensivos — Muralha, Colosso, Protetor,
> Regenerador etc. — trocam pelo **modelo pesado da mesma família, quando
> existir**): Pele Fina→Pele Grossa · Couro Leve→Couro Pesado ·
> Escamas Leves→Escamas Pesadas · Carapaça Leve→Carapaça Pesada ·
> Placas Leves→Placas Pesadas · Exoesqueleto→Exoesqueleto Fundido.
> Modelos já pesados (Couro Pesado, Pele Grossa, Escamas Pesadas, Pele de Pedra,
> Placas Pesadas, Exoesqueleto Fundido, Elemental, Psíquica) **não trocam de
> material** — o tanque cresce pelo atributo, não por escala de lagarto em
> cavalo.

## Histórico

- v1 base 10–16 + atributo: fracos altos (12–14), Felinos 17 no ND 1, min-max 28 cedo.
- v2 base + atributo/2 + ND/3: descartada (dividia o atributo, que sobe devagar ~1/ND).
- v3 base 8–16 + atributo: ND 1 fraco 10–12, teto 28.
- **v4 (esta):** bases do autor — leves 6–10, médias 12–14, pesadas 14–16;
  Armadura Psíquica 8+Sab para mentais/incorpóreos; teto 28 mantido.
